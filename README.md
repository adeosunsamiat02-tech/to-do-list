# ✅ To-Do List App

A simple, responsive To-Do List app built with HTML, CSS, and JavaScript. Add, check, and delete tasks with local storage support.

### 🔗 Live Demo
https://to-do-list-xqi8.onrender.com

### ✨ Features
- ➕ Add new tasks
- ✅ Mark tasks as completed with custom icons
- 🗑️ Delete tasks
- 💾 Saves tasks automatically with LocalStorage
- 📱 Fully responsive - works on mobile and desktop

### 🛠️ Built With
- HTML5
- CSS3
- JavaScript (Vanilla - No Frameworks)

### 📚 What I Learned
I learned DOM manipulation, event listeners, localStorage, and fixing image paths in CSS.
